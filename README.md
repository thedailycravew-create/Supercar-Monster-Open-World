# Supercar Monster Open World — Prototype 0.1

This is a starter Godot 4 project for a third-person open-world action game.

## Run it
1. Install Godot Engine 4.x (standard edition) from https://godotengine.org/
2. Extract this ZIP.
3. Open Godot Project Manager → Import → select `project.godot`.
4. Open the project and press F6 or F5.

## Controls
- W A S D: move
- Mouse: look around
- Shift: sprint
- Space: jump
- Esc: release mouse; click the game window to capture it again

## Current prototype
- Third-person player capsule and follow camera
- Simple blockout city and ground collision
- Glowing mission marker
- Keyboard/mouse controls
